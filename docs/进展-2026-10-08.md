# 2026-10-08 进展：本仓自建 wheel 入库口径（放行 SDK wheel）

## 背景

跨仓口径（2026-10-08，用户；登记在 `ikc-demo` 的 `AGENTS.md` §11-2）：
**每个仓自己构建的 `.whl` 允许推送**——判据是「这只 wheel 由本仓构建」，**不是包名前缀**。

本仓 `.gitignore` 的 `dist/` 是**任意层级**规则，把 `sdk/python/dist/` 也盖住了：
`semantica_graph_sdk-0.1.0 / 0.1.1-py3-none-any.whl`（本仓自建 SDK；`0.1.1` = 当前
`sdk/python/pyproject.toml` 版本）一直没能入库，离线安装只能就地重打 wheel。

## 本次落地

- `.gitignore`：服务端产物照旧不入库（`dist/`、`build/`；`docker/images/` 的 GB 级镜像包见既有规则），
  对 SDK 目录开一条**只放行 wheel** 的通道：`!sdk/python/dist/` + `sdk/python/dist/*` +
  `!sdk/python/dist/*.whl`。
- 归档 `sdk/python/dist/semantica_graph_sdk-0.1.0-py3-none-any.whl` 与 `-0.1.1-py3-none-any.whl`。
- 发布边界不变（`AGENTS.md` 发布契约）：SDK（`sdk/python`，dist 名 `semantica-graph-sdk`）才发 PyPI；
  服务端包 `graph-engine` 以 wheel / 镜像分发。

## 验证

- `git status -uall` 只多出上述两只 wheel；同目录 `.tar.gz` 仍被 `sdk/python/dist/*` 忽略。
- `git check-ignore -v sdk/python/dist/semantica_graph_sdk-0.1.1-py3-none-any.whl` → 末条为取反规则
  （不再被忽略）。
