# 进展 2026-10-01：图存储后端缺省切 Neo4j（`GRAPH_ENGINE_STORE_BACKEND`，0.1.2 → 0.2.0）

## 目标

`ikc-neo4j`（`scripts/build_neo4j.sh` 备镜像 / `scripts/docker-run-neo4j.sh` 起停）此前只是「起好备用」——
引擎图数据落本地 SQLite `engine.db`，外部图库没接进数据面。本轮把**图存储后端缺省切到 Neo4j**。

## 落地

- 新增 `graph_engine/persistence/neo4j_store.py`（`Neo4jGraphStore`）：与 `SqliteGraphStore` **同接口同语义**，
  四类标签 `GraphEngineGraph` / `GraphEngineEntity` / `GraphEngineRelation` / `GraphEngineJob`，属性名与 SQLite
  列一一对应（`*_json` 两边都是 JSON 文本）；关系以**节点镜像**落库（不做真实 Neo4j 关系，避免端点缺失时在读面
  造「幽灵记录」）。合并 / 增量废弃 / 作业台账 / `neighbors` / `paths` / `stat` / `export_lines` 复用同一套口径。
- `graph_engine/config.py`：新增 `GRAPH_ENGINE_STORE_BACKEND`（**缺省 `neo4j`**）与
  `GRAPH_ENGINE_NEO4J_{URI,USER,PASSWORD,DATABASE}`。
- `graph_engine/persistence/__init__.py`：新工厂 `create_store()`；显式 `db_path` 或 `=sqlite` 走 SQLite
  （CLI `--db-path` 与既有测试口径不变）；驱动缺失 / 连接失败 / 后端名非法 → **告警降级 SQLite**（不拦启动）。
  `graph_engine/runtime.py` 改用工厂；`application/service.py` 注解放宽为 `GraphStore`。
- 依赖：新文件 `requirements-neo4j.txt`（`neo4j>=5.0,<7`），Dockerfile **独立一层**装入；`requirements.txt`
  保持字节不变（它一变，semantica/torch 等数 GB 依赖层缓存全失效）。`pyproject.toml` 增 `[neo4j]` extra。
- 入口 / 部署：`docker/entrypoint.sh` 容器视角缺省 `GRAPH_ENGINE_NEO4J_URI=bolt://host.docker.internal:7687`；
  `docker-compose.yml` / `docker/.env.example` 加键并注明「同网络容器可改 `bolt://neo4j:7687`；图库不可达降级 SQLite」。
- 文档：`README.md`、`AGENTS.md`、`docs/解决方案.md` §7（切图库改为「已落地」）、
  `docs/本地Docker部署手册.md` §7.5 + 排障表。
